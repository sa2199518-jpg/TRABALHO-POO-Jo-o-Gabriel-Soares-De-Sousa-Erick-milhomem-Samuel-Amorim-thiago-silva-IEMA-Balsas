# TRABALHO-POO-Jo-o-Gabriel-Soares-De-Sousa-Erick-milhomem-Samuel-Amorim-thiago-silva-IEMA-Balsas
TRABALHO DE PROGRAMACAO ORIENTADA A OBJETOS, MODELAGEM UML DE UM SISTEMA SIMPLES DE BIBLIOTECA COM 8 CLASSES, METODOS E ATRIBUTOS QUE SE COMUNICAM COM SENTIDO.

Sistema de Biblioteca
Sistema simples de gerenciamento de uma biblioteca, desenvolvido com base em um modelo UML e conceitos de orientação a objetos.

Funcionalidades
Cadastro de usuários, funcionários, livros e autores

Controle de exemplares

Registro de empréstimos e devoluções

Controle de disponibilidade

Cálculo e pagamento de multas por atraso

Principais classes
Pessoa é a classe base de Usuario e Funcionario.

O sistema também possui as classes:

Livro

Autor

Exemplar

Emprestimo

Multa

O projeto tem como objetivo praticar POO, herança, associação e composição em um sistema simples de biblioteca.
